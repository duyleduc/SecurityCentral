# SecurityCentral UI Wireframes (All Pages)

## Overview
These low‑fidelity wireframes cover the full UI: overview, lists, and detail pages. The goal is to make status and risk understandable at a glance for non‑security teams.

## Notes
- The **Project toggle** filters charts and cards across all assets.
- Tables are avoided; cards + charts provide the “at a glance” view.
- Detailed lists can live behind each card or chart section if needed.
