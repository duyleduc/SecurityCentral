💡 Why this design

  • Same header shape (grade · name · status · type chip · tags · last activity) for every asset.
  • Same 4 tabs (Overview / Activity / Security / Settings) for every asset.
  • "What needs attention" block surfaces the top issues inline — you don't need to drill into Security unless you want detail.
  • Security tab keeps the deep dive (current posture / vulnerabilities / attack-surface sub-tabs for servers).
  • Activity tab centralizes heartbeats, scans, cert renewals, posture snapshots — same pattern everywhere.
  • Print/Export replaces the dedicated "Full Report" route — same data, less navigation.
