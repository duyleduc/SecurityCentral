CVE-2024-1234

Remote code execution via prototype pollution in lodash
Detected on auth-service · first seen 2h ago · source: code_dependencies

Description

A type confusion issue in lodash's _.set() allows an attacker to assign to Object.prototype, enabling arbitrary code execution when the polluted prototype is later accessed. Affects versions before 4.17.21.

💡 Remediation

# Upgrade lodash to patched version
npm install lodash@4.17.21
npm audit fix
