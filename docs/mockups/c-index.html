What changes on every page

  1. Top bar project switcher pill — clicking opens a dropdown (production, staging, customer-foo, All projects, + New project). Selection is persisted in the URL (?project=prod).
  2. Per-page "Project" filter dropdowns removed — the scope is already set globally. List pages keep Tag and Status filters but drop Project.
  3. Scope banner under the page title reminds users what's filtered: "Showing production only · view all projects".
  4. Normalized status chips: healthy at-risk critical unknown — used on every asset (server / domain / repo).
  5. Separate operational state: ● up ○ down — shown alongside health, not merged into it.
  6. Work-state vocabulary for findings & invitations: ○ new in-progress resolved ✕ dismissed
